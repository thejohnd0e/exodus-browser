# Cookies: Import and Export — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Import cookies from Dolphin JSON and Netscape into a stopped profile and export them back without allowing the temporary browser to access the network.

**Architecture:** Read and normalize the file in main; then, under `withStopped`, start headless Chromium on the same `user-data-dir` with a dead loopback proxy and blocked DNS, set/read cookies through CDP, and close the browser. The renderer receives only the count and filename.

**Tech Stack:** Electron 45, TypeScript strict, React 19, Zod 4, SQLite (`better-sqlite3`), built-in WebSocket, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-30-cookies-design.md` (based on `docs/superpowers/specs/2026-10-30-fingerprint-geolocation-cookies-design.md`, §1 and §4.5).

## Global Constraints

- Windows x64, Node 22; no new npm dependencies.
- Cookie values never reach the renderer, DTOs, argv, logs, or error text.
- The temporary session has no network access: `--headless=new`, a dead loopback proxy, `--host-resolver-rules=MAP * ~NOTFOUND`, `--disable-background-networking`, no navigation.
- Import and export only for stopped profiles, under `supervisor.withStopped`.
- Use the same engine as the profile (`installer.resolveExecutable()`); no engine → `ENGINE_NOT_READY`.
- Limits: 5 MiB file, 20 000 entries; domain ≤ 256, path ≤ 1024, name ≤ 1024, value ≤ 8192 bytes.
- `storeId ≠ "0"` is unsupported; partitioned cookies are not exported.
- Strict UTF-8 with BOM removal; control characters in values reject the entire file.
- Tests: `npm run verify`, `npm run test:integration`.
- Conventional commits: `feat:`, `fix:`, `test:`, `docs:`.

## Review Focus

1. Cookie value contains a tab or newline: reject the file with `INVALID_COOKIE_FILE` and import nothing (Task 2).
2. Profile has a nonworking proxy: cookie import and export succeed; profile launch still fails with `PROXY_UNREACHABLE` (Task 5, Task 9).
3. Expiration in seconds and milliseconds, and > 400 days: import the cookie and find it during read-back verification; export does not fail (Task 2, Task 9).
4. Netscape file from curl with `#HttpOnly_` and `FALSE` in the second field: preserve httpOnly and host-only on import and export (Task 3).
5. Import for a running profile is rejected with `PROFILE_BUSY`; exiting the application during import closes the temporary browser (Task 5, Task 7).
