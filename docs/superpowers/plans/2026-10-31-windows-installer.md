# Windows Installer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a branded Windows NSIS setup wizard with selectable install directory, per-user default and an administrator option for machine-wide installation.

**Architecture:** Add pinned electron-builder as a development dependency, configure its NSIS target in `package.json`, and build from the existing `dist/` app bundle into `dist-install/`. Reuse the approved PNG artwork by committing a reproducibly generated ICO; keep app data and engine downloads in their existing user-data location.

**Tech Stack:** Electron 45, electron-builder, NSIS, npm, PowerShell/Windows.

**Spec:** `docs/superpowers/specs/2026-10-31-windows-installer-design.md`

## Global Constraints

- `npm run dist` produces `ExodusBrowser-Setup-<version>.exe` from the existing production build.
- NSIS is assisted (`oneClick: false`), defaults to per-user, allows install-directory changes and elevation for machine-wide installation.
- Start Menu shortcut is created; desktop shortcut is optional; finish page can launch Exodus Browser.
- Uninstall must not remove `%APPDATA%\Local Profiles` or its downloaded engine.
- Do not bundle Chromium, add signing, auto-update, portable, x86, or ARM targets.
- electron-builder is development-only; `better-sqlite3` is unpacked from asar.
- Installer files go in ignored `dist-install/`; ICO is committed and builds need no image-conversion tool.
- Published copy, tests, and docs remain English; preserve legacy data path and app.setName compatibility.

## Review Focus

- Building on a clean checkout without the local build counter initialized must follow the existing build script contract; test `npm run dist` and ensure the release artifact is emitted without changing/committing local counter state.
- Native `better-sqlite3` must resolve after packaging; validate the packaged app can start and open its SQLite store.
- Per-user installation must not prompt for elevation by default; exercise the default destination and launch path.
- Machine-wide choice must be available to an administrator and install under Program Files; verify with a real elevated install only where authorized.
- Uninstall must leave user data untouched; test with a temporary data-root override and a sentinel file.
