# Local flag assets

The SVGs in this directory are copied from `flag-icons` 7.6.0, `flags/4x3`, and bundled locally. The source collection is licensed under MIT; its complete license text is in `LICENSE.flag-icons.txt`.

Upstream: <https://github.com/lipis/flag-icons>

To refresh, install the exact pinned package version from the lockfile, copy only its `flags/4x3/*.svg` files here, and copy its `LICENSE` to `LICENSE.flag-icons.txt`. Review the changes and keep the package version in this inventory synchronized. The renderer maps validated ISO alpha-2 codes to these already-bundled assets; it does not construct paths from user or database strings.
